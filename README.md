# Biomarker-selected-trial-landscape
R pipeline mining 63,862 ClinicalTrials.gov oncology trials (2005–2025) for biomarker-selected designs. Text-mines eligibility criteria to track trends by tumour, biomarker, drug type, region and sponsor, and links activity to FDA approvals. Biomarker selection rose from 8% to 21%. Includes report, Shiny dashboard and tests.
